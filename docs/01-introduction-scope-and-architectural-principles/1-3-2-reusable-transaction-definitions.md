# 1.3.2 Generalized Transaction Definitions and the Reusable Transaction Catalog

A **Generalized Transaction Definition (GenTXDef)** describes a reusable information exchange transaction without binding it unnecessarily to one business use case. GenTXDefs are reviewed and maintained under DirectTrust/MAP governance in the **Reusable Transaction Catalog (RTC)**. The RTC provides a governed inventory and a stable reference point for transaction identity, purpose, participating actors, functional responsibilities, and processing semantics.

GenTXDefs intentionally leave appropriate variation in terminology bindings, cardinalities, content choices, and permitted processing options. Such flexibility is specified, not assumed: a GenTXDef identifies which requirements are invariant and which choices a UC IG is expected or permitted to constrain. Generalization must not erase the behavior that makes a transaction recognizable and interoperable.

RTC governance and the conventions used to author a GenTXDef are distinct from exchange conformance. For example, a prescribed chapter heading or catalog review procedure does not, merely by appearing in the RTC authoring process, create an obligation for an implementing sender or receiver. The applicable Framework and transaction requirements establish those obligations.

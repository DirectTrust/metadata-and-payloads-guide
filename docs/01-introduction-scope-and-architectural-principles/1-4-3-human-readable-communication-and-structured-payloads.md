# 1.4.3 Human-Readable Communication and Structured Payloads

MAP supports human-readable communication alongside structured, machine-processable information. When both forms convey the same information, they should remain consistent; the structured package must not silently diverge from the human-readable representation intended for the recipient.

The specific packaging and copy-preservation rules are addressed in Chapter 3.8, including the common MIME packaging requirements. Human readability is an interoperability capability, not an excuse to omit required structured content.

# 1.5.3 Use-Case-Specific Constraints

A UCTXDef turns a reusable transaction pattern into an implementable use-case contract. It identifies the particular business context, information objects, coded values, permitted occurrences, actor responsibilities, and transaction processing expectations that apply to the use case. These choices should be sufficiently explicit for independent implementers to reach compatible results.

The UC IG should distinguish constraints inherited unchanged from a GenTXDef, choices specialized within permitted variation, and genuinely new requirements. A newly authored UCTXDef should be identified as such rather than presented as an RTC-approved transaction. Use-case-specific bindings do not automatically change the generalized catalog definition.

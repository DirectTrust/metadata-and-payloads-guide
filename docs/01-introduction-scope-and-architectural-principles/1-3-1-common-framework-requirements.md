# 1.3.1 Common Framework Requirements

Common requirements apply across MAP transactions to the extent stated by their scope and conditions. They include shared terminology and rules for transaction architecture, actor accountability, information identity, payload and metadata structure, message packaging, and interpretation of exchange outcomes.

A common requirement should be stated once and referenced by TX Definitions and use-case IGs. If a rule is specific to one transaction, it belongs in that TX Definition rather than being presented as universally applicable.

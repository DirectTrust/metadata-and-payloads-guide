## Enabling Interoperable Information Exchange Using Direct

The MAP Framework establishes a common architectural foundation for interoperable information exchange using Direct. It comprises three complementary subframeworks: the MAP Use Case Framework, the MAP Transaction Framework, and the MAP Endpoint Capability Statement Framework. Together, they support the definition of business information exchange needs, the specification of reusable transaction behavior, and the communication of endpoint capabilities needed for interoperable implementation.

# 1.4.4 Progressive Interoperability and Minimally Structured Documents

Interoperability can improve progressively as communities move from exchangeable human-readable information toward richer metadata and discrete data without discarding useful document workflows. A **minimally structured document** can preserve a readable representation while introducing a small, reliable set of machine-interpretable elements.

MAP does not classify information as simply structured versus unstructured. The degree and kind of structure should be appropriate to the intended processing and should be increased when it yields demonstrable benefit.

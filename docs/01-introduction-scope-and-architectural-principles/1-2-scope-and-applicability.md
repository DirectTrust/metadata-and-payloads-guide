# 1.2 Scope and Applicability

MAP applies to the exchange-level conventions specified in this Framework and the TX Definitions that adopt them. It is designed for use across clinical, administrative, legal, social, and other information domains, with domain-specific payload specifications supplied by appropriate standards and use-case IGs.

The Framework is extensible. A use-case IG may specialize or constrain supported behavior within the limits of the common architecture; materially different transaction behavior should be addressed through an appropriate reusable TX Definition rather than an unannounced local reinterpretation.

# 1.2.3 Relationship to Existing Standards and Implementation Guides

MAP builds on, and does not replace, Direct, SMTP/MIME/S/MIME, IHE XD-family concepts, HL7 CDA, HL7 FHIR, HL7 V2, and other referenced specifications. Where a specialized content artifact requires a profile or template, its governing standard or IG remains authoritative for that artifact.

MAP's contribution is to specify how exchange participants use compatible message, metadata, payload, and transaction conventions together. A derivative IG should identify the external specifications and versions it actually requires.

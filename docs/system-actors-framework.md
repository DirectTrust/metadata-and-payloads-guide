# System Actors Framework

System Actors represent the types of systems these entities have already deployed (or would likely be to deploy). Identifying the System Actors helps to explain where the use of Direct Secure Messaging technology fits for this scenario. These are the systems which will be expected to implement technical actors defined in this IG.

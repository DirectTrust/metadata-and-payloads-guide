# 2.6 Diagrams and Examples

The following diagrams illustrate the six accepted MAP Framework objectives using the scenarios, activities, and coverage analysis in Sections 2.4 and 2.5. They complement Figures 2-1 through 2-3, which establish business and technical actor relationships. These conceptual illustrations do not assert compatibility of any RTC GenTXDef absent the evaluation described in Section 2.4.2.

This may be one diagram or multiple. It needs to show

Requirements for all transactions to support human readability in the message body and carried in the structured package.

Option to request a workflow-status report to be returned to indicate if the transaction’s payload was accepted into the intended workflow or not.

Guidance provided on Provenance Responsibilities across an information exchange transaction and how to include relevant Provenance attestations to accompany the transaction.

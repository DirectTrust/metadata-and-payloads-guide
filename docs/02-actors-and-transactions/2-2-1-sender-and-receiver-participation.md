# 2.2.1 Sender and Receiver Participation

The **Sender** initiates the specified transfer or report toward the **Receiver** for the transaction's shared purpose. The Receiver is the intended participant for the defined processing obligation. A message's immediate SMTP peer or intermediary is not necessarily the transaction's business Receiver.

Functional requirements for each participation role belong in the applicable TX Definition, especially Chapter 6. The common Framework supplies the distinction, not a universal set of identical responsibilities for all transactions.

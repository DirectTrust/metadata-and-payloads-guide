# Endpoint Capability Declaration Document

The Endpoint CapabilityStatement contains contact information for requesting additional information or authorization to access services offered by the organization through the endpoint. It also provides a natural language description of the capabilities supported by the endpoint to help people understand what the endpoint is established to offer and support.

A derived Use Case IG specifies expectations for how a CapabilityStatement SHOULD/SHALL/MAY be created for an endpoint that supports one or more of the use cases in scope for that derived Use Case IG. The CapabilityStatement for an endpoint supporting a specified use case includes information that would be useful to an organization that is interested in sharing data via that endpoint. Note, the receiving endpoint SHOULD be included in the DirectTrust Aggregated Directory to support adoption of implemented use cases.

Chapter 6 Endpoint Capability Declaration Document in Framework Part II lists key CapabilityStatement fields and describes how to populate each for an endpoint that supports a specific use case.

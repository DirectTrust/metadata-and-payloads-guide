# Actor and Transaction Framework

This section establishes a framework for creating one or more Actor Transaction Diagrams that show the full range of needed message transactions needed to cover the aspects of the Business Scenario which are in scope. The actor transaction diagrams enable a list of transactions to be constructed and described in terms of each message’s needed payload.

It establishes names for the basic Business Actors played by Organizational Entities and Individuals involved in this scenario. It also establishes a set of System Actors which represent the systems that these Business Actors would be using. If the scenario includes two-actor and three-actor use cases, it identifies Business and System Actors for both of these situations.

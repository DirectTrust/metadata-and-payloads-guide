# 5.1 Applying the MAP Framework

Implementers begin with the applicable Use Case Implementation Guide to identify the business objectives, participating actors, required information exchanges, and selected transactions.

Chapter 2 describes the common actor and transaction architecture. Chapter 3 establishes common transaction requirements and provides the framework for applicable Generalized Transaction Definitions (GenTXDefs) and Use Case Transaction Definitions (UCTXDefs). Chapter 4 provides guidance for communicating endpoint capabilities.

Implementers should use the applicable Transaction Definitions to determine the requirements governing each transaction. The Framework’s common architecture does not imply that every transaction or implementation option applies to every use case.

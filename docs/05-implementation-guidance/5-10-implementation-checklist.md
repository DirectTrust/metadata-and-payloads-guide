# 5.10 Implementation Checklist

For each applicable UCTXDef, verify: correct Shared Activity and transaction identity; authorized Routing Target; declared endpoint capabilities; required structured payload, metadata, Context, identifiers, information objects and human-readable copies; Task only when required or elected; independently attributable Provenance; message delivery distinct from workflow acceptance; any explicitly required status reporting; and appropriate authority, oversight, and remediation when AI is used.

# 5.3 Supporting Resources

The MAP Framework provides supporting resources for implementation, including Terms and Definitions, References, Vocabulary, Examples, and Appendix D — FHIR Collection Bundle Packaging.

The Vocabulary package provides terminology artifacts used by the specifications. Appendix D provides the FHIR Collection Bundle representation and mapping details. Examples and supplementary Implementer Guidance may illustrate implementation approaches but do not independently establish requirements.

Implementers should consult the applicable specifications for authoritative requirements and use supporting resources for additional clarification and practical assistance.

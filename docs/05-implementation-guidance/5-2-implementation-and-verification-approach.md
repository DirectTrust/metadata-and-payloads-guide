# 5.2 Implementation and Verification Approach

A practical implementation sequence is to identify the applicable transactions and actor responsibilities; determine the supported information objects, metadata representations, and exchange options; implement the required exchange behavior; and verify the results with participating systems.

Verification should address both technical interoperability and the intended workflow outcome. Successful message delivery, valid payload structure, and acceptance of information into a receiving workflow are distinct considerations.

Implementers should use the requirements and conformance provisions of the applicable specifications as the basis for verification. This chapter does not establish an additional testing or certification program.

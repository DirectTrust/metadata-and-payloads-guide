# Chapter 7 — Appendices

The appendices collect supporting explanations, mappings, worked architectural formations, and reference material for the Metadata and Payloads (MAP) Framework. They are subordinate to this single appendices chapter, rather than separate peer chapters. They explain and illustrate the framework without independently establishing new transaction conformance requirements.

Each appendix retains its letter identifier so that existing conceptual references to Appendix A through Appendix H remain meaningful. The sections below provide the navigation into those appendices.

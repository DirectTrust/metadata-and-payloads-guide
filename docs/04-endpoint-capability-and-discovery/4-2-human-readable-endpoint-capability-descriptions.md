# 4.2 Human-Readable Endpoint Capability Descriptions

An endpoint operator SHOULD publish a human-readable description of its supported interoperability capabilities at a stable, publicly accessible web address.

The description may be presented as an HTML page, PDF document, or another format that can be accessed and understood without specialized software.

The description SHOULD provide sufficient information for a prospective exchange partner to understand the endpoint’s supported capabilities and any material limitations affecting interoperability.

An endpoint operator SHOULD keep its published description reasonably current and identify when it was last updated.

The capability description need not reproduce the applicable Implementation Guides, Transaction Definitions, terminology packages, or technical specifications. References to those specifications may be used to identify established requirements and supported implementation options.

The publication of a capability description does not, by itself, establish conformance to a Transaction Definition.

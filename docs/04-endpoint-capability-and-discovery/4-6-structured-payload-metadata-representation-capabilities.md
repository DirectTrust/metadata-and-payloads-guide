# 4.6 Structured Payload Metadata Representation Capabilities

Structured payload metadata representation is distinct from information-object format. Endpoints declare Sender Actor and Receiver Actor support independently for each applicable representation, such as XD or FHIR metadata, where defined by the applicable technical specifications. When multiple representations are supported, declare a preference or use an explicit deterministic selection agreement. The presence of a FHIR information object does not imply support for FHIR package metadata.

Specific representation codes and profile versions must be established by the governing terminology and implementation artifacts; later maternal-health code inventories are not assumed to have been approved in this baseline.

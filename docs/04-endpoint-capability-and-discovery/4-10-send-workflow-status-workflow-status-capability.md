# 4.10 TX8 Workflow Status Capability

Workflow-status reporting is conditional on the applicable transaction requirements. Support for originating transactions does not by itself imply support for a particular workflow-status reporting transaction. When such a transaction is defined, its Sender Actor and Receiver Actor capabilities SHALL be independently declared and verified. Detailed report structure, routing, deadlines, and conformance rules belong to the applicable Transaction Definition rather than being presumed from this Framework alone.

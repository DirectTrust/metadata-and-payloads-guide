# 4.5 Transaction Capabilities and Technical Actor Roles

An endpoint declares support for each transaction it implements using the canonical identity established by the applicable Use-Case Transaction Definition. The Reusable Transaction Catalog (RTC) is architecturally established but has no Generalized Transaction Definitions (GenTXDefs) in this baseline. Transaction numbers in a future use-case guide are local navigation labels, not interoperable identities.

Sender Actor and Receiver Actor capabilities SHALL be declared independently. Organization type does not establish either capability. Conformance testing evaluates the capabilities actually declared and the applicable transaction requirements. A development-target declaration SHALL NOT be represented as a deployed endpoint capability.
